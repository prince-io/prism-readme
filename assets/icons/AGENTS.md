# assets/icons/ — imported sprites

## Purpose
- Self-contained snippets for pixel art imported from raster sources, reused inside banners and as standalone images.

## Ownership
- `<slug>.svg` — one per imported icon, generated by `../../tools/convert.py` from a raster source (PNG, or SVG wrapping an embedded image) and registered in `../../tools/imported_icons.json`.

## Local Contracts
- Generated output: edit the source image or `convert.py`, then regenerate — never hand-edit these files.
- Each file carries its own local exact palette (`--pf-<slug>-n`); these are **not** in `themes/*.json`, so the sprite looks the same in every theme.
- The body is a single `<g id="i-<slug>">` whose `<rect>`s use px coordinates, so the group can be copied into a banner `<defs>`.
- Flat, hard-alpha, axis-aligned pixel art only.

## Work Guidance
- **Add** — `python3 tools/convert.py <image-or-dir> --out assets/icons` (needs Pillow; default `--cell 3`; registry `../../tools/imported_icons.json`). Writes `assets/icons/<slug>.svg` and registers `<slug>`.
- **Use** — reference `<slug>` in a banner config: `"icons": [{ "id": "<slug>", "x": .., "y": .., "scale": .. }]`, or `line.bullet.id`.
- **Remove** — delete `assets/icons/<slug>.svg`, remove the `<slug>` key from `../../tools/imported_icons.json`, and drop every banner reference (a missing id fails the build).
- Refresh the reference sheet with `python3 tools/icons.py`, then rebuild: `python3 tools/build.py && python3 tools/check.py`.

## Verification
- `python3 tools/check.py` (parses, unique ids, no raw hex outside token/style blocks).
